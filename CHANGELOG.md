# Changelog

## 0.1.0 — 2026-11-04

Initial release.

- Browser app with synthetic demo, request waterfall, error/slow/repeated filters and local URL view.
- Reconstructed Markdown, script-free HTML and HAR metadata exports; CLI adds JSON.
- Shared dependency-free analysis core and bounded local input processing.
- Opaque origin/route aliases, relative timestamps and omission inventory.
- Nine README languages: English, Vietnamese, Korean, Japanese, Spanish, Brazilian Portuguese, Simplified Chinese, Thai and French.
- Meaningful core and CLI regression tests, syntax checks and offline build.

### Limits

50 MiB / 20,000 requests. Metadata can still be sensitive. Reports omit endpoint meaning and payload context. Reconstructed HAR uses documented placeholders for generic viewers. No guarantee of anonymity, exact diagnosis, adoption or star growth.
